# 2026-08-08

* **Update**: [Editor keys](/reference/editor-keys.md) gained the five periodic notes and the keys that open them, `<leader>gd`, `gw`, `gm`, `gq` and `gy`, which finish the `g` group. A new section says where each note lives under `01 Periodic`, what a fresh one starts with, and why the links back, up and on are written whether or not the notes on either side exist yet.
* **Update**: [Editor keys](/reference/editor-keys.md) says the week is the ISO one, counted from its Thursday, so 2027-01-01 opens `2026-W53` and that week links up to `2026-12`. The status bar's calendar week was already counted this way; the fix behind it was that the count rounded a part-week up, which put every week of a year whose January 1 is not a Thursday one too high.
* **Update**: [Editor keys](/reference/editor-keys.md) says opening a note takes the focus with it, from the file tree as well as from the finder, search, a wikilink and the periodic keys. The editor claims the focus only when nothing else holds it and the tree holds it, so a note opened from there used to arrive on screen with every following key still reaching the tree.
