# 2026-09-29

* **Update**: an `![](https://…)` draws the picture rather than its source. A note clipped from the web links its pictures and holds none of them, so the policy's `img-src` gains `https:` in `csp.ts` and `nginx.conf` alike, and `imageSource` hands such an address back as it stands. The picture goes out with `referrerpolicy="no-referrer"`, which keeps the note's name from the host and gets past the hotlink checks that read the referrer. `http:` and every other scheme stay as text, a page served over https refusing them as mixed content. The price is that the host learns the page was opened, and that a book can now load a remote image too; an image runs no code, so `script-src` is untouched. [Editor keys](/reference/editor-keys.md) and [Live preview](/explanation/live-preview.md) say so.
* **Correction**: a long note drew only its opening screens, the rest showing raw markdown (`###` in front of a heading, `![](…)` in place of a picture) until the cursor moved. CodeMirror parses the first few thousand characters when a note opens and the rest in slices afterwards, each slice arriving as a transaction that changes neither the document nor the selection, and the live preview's field rebuilt on neither. It now also rebuilds when the syntax tree has grown. The clipped Databricks article is what showed it: its first picture drew and the other three stayed text.
* **Update**: `<leader>cv` writes the transcript of the note's video into the note, under `## Transcript` at the end, so what was said can be read and searched. New route `GET /api/transcripts/{video_id}` reads the captions with `youtube-transcript-api` (MIT, read off its LICENSE file), on a worker thread because the library is synchronous. It takes a person's English track first, then YouTube's generated English, then the first track there is, and answers with the language, whether the track is generated and every caption with its start. The id must match `[A-Za-z0-9_-]{11}`, which keeps the route from fetching an address someone chose. No transcript, transcripts turned off and an unavailable video are a `404`; YouTube refusing the request is a `502`. New module `transcript.ts` joins the captions into paragraphs that end on a sentence after thirty seconds or at a minute regardless, each opening on `[mm:ss]` or `[h:mm:ss]`, decodes the entities YouTube leaves in and joins wrapped lines. A second press replaces the section rather than adding one, and the whole write is one change, so one `u` undoes it. It reads the first video the note links rather than the one the pane is showing, which the pane keeps to itself; that shortcut carries a `ponytail:` note. [Editor keys](/reference/editor-keys.md#its-transcript-in-the-note), [HTTP API](/reference/http-api.md#get-apitranscriptsvideo_id).
* **Update**: a thought reaches today's `## Dump` from anywhere, rather than waiting for the ritual at 17:00. New route `POST /api/dump` takes the text and the sender's own date, and appends the text as a paragraph at the end of the dump in that day's daily note, before any section that follows it. The note is made where the vault has none, exactly as `<leader>gd` makes it, and the section at the end of the note where the note has none. The daily template now has a second copy in `periodic.py` beside `periodic.ts`, both checked against `frontend/tests/fixtures/daily-notes.json`. [HTTP API](/reference/http-api.md#post-apidump).
* **Update**: `<leader>cd` opens a one-line prompt over whatever pane has the focus, and Enter sends the line to the dump and leaves the focus where it was, with a line in the status bar saying it landed. A test now fails when a leader binding would shadow a longer one. [Editor keys](/reference/editor-keys.md#capturing-into-todays-dump).
* **Update**: `/capture` is the same capture on a page sized for a phone, with a web app manifest that lets Android install it and share into it. A shared web address also offers **Clip to inbox**, which runs the import `<leader>cw` runs; that import moved into `clip.ts` as `importPage` so both callers share it. The manifest is served as `application/manifest+json` by a location of its own in `nginx.conf`, and linked with `crossorigin="use-credentials"` so oauth2-proxy sees the session. The content security policy is unchanged. iOS has no share target. Added [Capture from your phone](/how-to/capture-from-your-phone.md).
* **Update**: the agent surface gains a sixth capability, `dump`, as the MCP tool `dump` and the route `POST /agent/dump`, both calling the function `POST /api/dump` calls. It needs the caller's date, there being no notion of the vault's timezone to default to. [The agent boundary](/explanation/the-agent-boundary.md#why-a-sixth-capability-is-acceptable) says why a sixth is acceptable, and every page that counted five now counts six. The model-facing guide and the curl skill say that a thought for later goes to the dump rather than the agent inbox. [Agent API](/reference/agent-api.md#post-agentdump).
