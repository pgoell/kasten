# 2026-10-16: Anki, embeds and the reader

* **Update**: [Flashcard format](/reference/flashcard-format.md#as-a-cloze) reads nested marks as Anki does since 2.1.56: in `{{c1::Canberra was {{c2::founded}} in 1913}}`, `c1` hides the whole span and `c2` hides `founded` alone, each level with its own hint. An outer mark never closed is text, and a lone brace still makes no mark. The line saying nested marks are not read is gone. [Import an Anki deck](/how-to/import-an-anki-deck.md) says a nested mark arrives whole, not as a highlight, and counts each number (#254).
* **Correction**: [Import an Anki deck](/how-to/import-an-anki-deck.md) says a brace written as an entity, `&#123;` or `&lbrace;`, breaks a cloze mark as a typed brace does, so `{{c1::&#123;}}` imports as `=={==` and is no longer lost when the Back Extra is empty, and that an inner mark kasten does not read, such as an empty `{{c2::}}`, is its text alone inside the outer mark (#333).
* **Correction**: [Import an Anki deck](/how-to/import-an-anki-deck.md) says a `::` that Anki shows inside a cloze answer but never divides on, one written as an entity such as `&#58;&#58;` or split by a tag, stays part of the answer, written as `&#58;`, and no longer becomes a hint (#335). Review shows `&#58;` as a colon on every card, as markdown does.

* **Correction**: [Flashcard format](/reference/flashcard-format.md#as-a-cloze) says a code span is code everywhere: a cloze mark or `!suspended` inside one is text, and a code span inside a mark is read whole, so ``{{c1::`a::b`}}`` asks `a::b` with no hint (#346, #347). It also says a `::` in a code span divides no card, and that a typed answer is compared without the backticks of its code spans. * **Correction**: [Import an Anki deck](/how-to/import-an-anki-deck.md) says a schedule comment in a cloze answer or hint, in code too, is written `<!--SR\:`, so `{{c1::&lt;!--SR:c1!2026-01-01,1,250--&gt;}}` imports as `{{c1::<!--SR\:c1!2026-01-01,1,250-->}}` and review no longer reads it as the schedule of `c1` (#351).
