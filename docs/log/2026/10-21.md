* **Update**: [Save path orderings](/reference/save-path-orderings/log-card.md) gained row L5: a line written under `## Log`, `## Done`, `## Time`, `## TODOs` or `## Highlights` finds its heading by the readers' rule, so a heading with trailing spaces takes the line rather than a second section, and one inside a fenced code block or the frontmatter is skipped (#746).
* **Fix**: a capture finds `## Dump` by the readers' rule, the same one as row L5. A `## Dump` in a fence or the frontmatter is skipped, and a fenced heading-shaped line no longer ends the dump. A note that ends inside an unclosed fence holding `## Dump` takes the capture under it (#749). New page [Save path orderings: the dump capture](/reference/save-path-orderings/dump-capture.md): rows D1 and D2.
* **Fix**: a capture never lands inside a fence and never leaves one open (#752). A note that ends inside an unclosed fence gets a closing line after its last line, and the capture goes after that. A capture that opens a fence gets a closer. A `## Dump` that sits only in an unclosed fence is no longer used: the fence is closed and a live `## Dump` is made at the end. Rows D2 to D4 of [Save path orderings: the dump capture](/reference/save-path-orderings/dump-capture.md) now cover this.
* **Fix**: a line written under a heading by `appendUnder` or `appendUnderEdit` never lands inside a fence. A note that ends inside an unclosed fence gets a closing line after its last line, and the line goes after that. A heading that sits only in an unclosed fence is no longer used: the fence is closed and a live heading is made at the end. In the editor the closer and the line are one change, so one `u` takes both back. The card's totals read inline triple-backtick code as no fence too, so the lines after it count. Rows L5 and L6 of [Save path orderings: the log card](/reference/save-path-orderings/log-card.md) now cover this (#755, #758).
