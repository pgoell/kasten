# 2026-10-05

* **Update**: [Editor keys](/reference/editor-keys.md) gained [The command palette](/reference/editor-keys.md#the-command-palette): `<leader>:` and `Ctrl+Shift+P` in a terminal open a box that runs any command by name, and a `/` in insert mode opens the same list, with headings, todos, a table and other inserts.
* **Update**: the agent surface gains an eighth capability, filing a PDF, an epub or an image. [Agent API](/reference/agent-api.md) gained `POST /agent/files/{path}`, which takes the raw bytes the way `POST /api/assets/{path}` does and runs the same function, and `POST /agent/files/{path}/fetch`, which downloads a public URL through the address checks `GET /api/fetch` makes. The MCP tool `save_file` takes a URL only, because a tool call is JSON a model writes and cannot carry a file. [The agent boundary](/explanation/the-agent-boundary.md) gained [Why an eighth capability is acceptable](/explanation/the-agent-boundary.md#why-an-eighth-capability-is-acceptable), which weighs the disk a book outside jj can fill and the network a download can reach. [Connect an agent](/how-to/connect-an-agent.md) says how Claude Code files a local file through the plugin even with MCP connected, and that a chat attachment in claude.ai or chatgpt.com cannot come in. The counts of seven in [HTTP API](/reference/http-api.md), [The security model](/explanation/security-model.md) and the explanation index now read eight.
* **Update**: the address check on a fetch moved into the connection. It used to resolve the name, check it, and leave httpx to resolve it again when connecting, so a name that answered a public address first and a private one second got past. Now a network backend under httpx looks the name up once, refuses it unless every address is public, and opens the socket to the address it checked; TLS still verifies against the name. Redirects connect the same way, so the per-hop loop went, and a redirect to a scheme other than `http` or `https` is now a `502`. `GET /api/fetch`, `POST /agent/files/{path}/fetch` and `save_file` share it. [HTTP API](/reference/http-api.md#get-apifetch), [The security model](/explanation/security-model.md) and [The agent boundary](/explanation/the-agent-boundary.md#why-an-eighth-capability-is-acceptable) no longer describe the gap.
* **Update**: the file tree draws the vault's HTML pages beside its notes, and a click shows one in a pane, its script included. [HTTP API](/reference/http-api.md) gained `GET /api/html` and `GET /api/html/{path}`, the second sending the page in a sandbox of its own. [Editor keys](/reference/editor-keys.md#the-file-tree) says what the tree and the pane do with a page. [Security model](/explanation/security-model.md#a-page-of-html-runs-as-nobody) says why the page runs in an origin that is nobody's, and the app's `frame-src` gained `'self'` for the frame.
