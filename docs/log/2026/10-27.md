* **Feature**: every request an agent token makes writes one row to the `token_action` table in Postgres: the time, the token's name, the client address, the MCP tool or the method and path, the note it named, the status and the outcome. A row never holds a secret or note text, and rows older than 90 days go. `/tokens` shows each token's last use, opens its recent actions and marks one unused for 30 days. A revoked token's record moves to `tokens-revoked.json`, so its requests stay named (#965). [Connect an agent](/how-to/connect-an-agent.md#what-kasten-records) says what is kept and where.
