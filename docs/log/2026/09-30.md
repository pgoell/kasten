# 2026-09-30

* **Creation**: Added [People in the vault](/explanation/people-in-the-vault.md), now that a note marked `type: Person` draws a card.
* **Update**: a person's card gathers what the vault holds on them: the open todos linking them soonest due first, the three most recent dated notes linking them, and the five most recent `- ✅` log lines that link them. It is drawn at the foot of the person's own note and, on `<leader>gp`, in a pane beside it; a second press moves to the card already open. A line counts only when it carries a wikilink resolving to the person's note, so a name written in prose is on nobody's card, which is the whole rule and the reason the card can be trusted. Nothing new was added to the backend: the card reads `GET /api/todos` and `GET /api/search` for the person's name, the two answers the todo pane and the backlinks panel already hold, and `person.ts` decides which of the lines are links. The vault's ontology note gained the `Person` type and `How-To-TODO` now asks agents to write the link. [Editor keys](/reference/editor-keys.md#the-person-card).
* **Creation**: Added [Graph query](/reference/graph-query.md) and [The graph](/explanation/the-graph.md), now that the vault draws as a graph and answers questions about its links.
* **Update**: the notes draw as a graph, the way Obsidian's do. `<leader>gg` puts the whole vault in the focused pane and `<leader>gl` the graph around the open note beside it, where `+` and `-` reach further out or pull back in. Each note is a dot sized by its edges and coloured by its `type`, a typed relation is a purple arrow, a note nobody has written is a hollow ring, names fade in with the zoom, and a hover lights one note's neighbourhood. The canvas is `force-graph` (MIT). [Editor keys](/reference/editor-keys.md#the-graph-pane).
* **Update**: the graph is queryable. New route `GET /api/graph` builds it from three `rg` passes per request, nothing indexed, and reads one query language in `graph.py`: a filter (`type:`, `tag:`, `path:`, `rel:`, `is:missing`, `is:orphan`, bare words, `-` to turn any round) or a pattern of triples and tests over `?variables` that answers in rows. The pane sends what is typed and draws what comes back, so there is one parser. The graph cuts `|alias` and `#heading` off a link, which the editor does not yet, and skips embeds of files. [HTTP API](/reference/http-api.md#get-apigraph), [Relation format](/reference/relation-format.md#how-the-graph-reads-it) no longer says there is no endpoint that reads relations.
* **Update**: the agent surface gains a seventh capability, a read: the MCP tool `query_graph` and the route `GET /agent/graph`, both calling the function `GET /api/graph` calls. [The agent boundary](/explanation/the-agent-boundary.md) says why a seventh is acceptable, every page that counted six now counts seven, and the model-facing guide and the curl skill name it. [Agent API](/reference/agent-api.md#get-agentgraph).
