# 2026-08-16

* **Correction**: the review overview counts a nested deck's cards once. The header summed every row, and a deck counts every card under it, so a card in `databases/postgres` was counted for the child and again for its parent: three imported Anki decks holding 488 cards between them read as `696 to go`, and answering one card dropped the number by two. The rows were right all along, the total was not. `review-decks.tsx` sums the top-level rows alone, which is every card exactly once because `deckPath` names a deck's parent whenever it names the deck. [The review pane](/reference/editor-keys/review-pane.md#the-review-pane) says what the overview draws.
* **Update**: `deploy/.env.prod.example` carries `KASTEN_FLASHCARDS_PATH=00 Inbox`. The default `03 Flashcards` would be a second folder numbered 03 in the production vault, beside `03 Areas`, so an imported deck lands in the inbox and is filed by hand. [Configuration](/reference/configuration.md#kasten_flashcards_path) says what the setting does.
