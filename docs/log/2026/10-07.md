# 2026-10-07

* **Update**: a note or a folder row in the file tree can be dragged onto a folder, onto a note's row to land in its folder, or onto the empty space for the vault root. A folder the pointer rests on unfolds after 600ms, and a drop asks first, listing every file the move would rewrite; Enter moves and Escape cancels. [Editor keys](/reference/editor-keys/file-tree.md#dragging-a-row).
* **Update**: new route `GET /api/move-preview` answers which files a move would rewrite and writes nothing. [HTTP API](/reference/http-api/moving.md#get-apimove-preview), whose count now reads thirty-four, as do [Agent API](/reference/agent-api.md) and [The agent boundary](/explanation/the-agent-boundary.md), which still said thirty-one.
* **Update**: a move rewrites relative markdown links as well as wikilinks, carries an entry in the old folder's `index.md` to the new folder's, and prunes a folder left holding only its index. Every folder kasten makes gets an `index.md` listing, an Anki import's included, and the outermost one gets a line in the index above it when that index is already a list of markdown links. A moved folder's index takes the new name as its heading when its heading was the old name. `GET /api/move-preview` lists the files whose links change, not these smaller writes. [HTTP API](/reference/http-api/moving.md#what-a-move-does-to-the-links), [Agent API](/reference/agent-api/routes.md#put-agentnotespath), [OKF in the vault](/explanation/okf-in-the-vault.md) and [Getting started](/tutorials/getting-started.md) say so, and the startup notes `How-To-Index.md` and `reading-this-vault.md` no longer say kasten leaves markdown links and indexes alone.
* **Update**: [Mise tasks](/reference/mise-tasks.md#vault-maintenance) gained `index:backfill`, which writes a listing into every folder below the vault root that has none.
* **Creation**: Added [Moving a note](/explanation/moving-notes.md): why links are rewritten before the rename, why a drop asks and the prompt does not, why an entry moves only when it was listed, why the backfill is not at startup, and why a lone index is pruned.
* **Update**: a daily note draws the day's weather under its line of links: per town, sky icons, an hourly temperature line, rain chance bars, sunrise, sunset and night shading. New route `GET /api/weather` reads it off Open-Meteo, and new setting `KASTEN_WEATHER_PLACES` names the towns. [HTTP API](/reference/http-api/capture.md#get-apiweather), whose count now reads thirty-five, as do [Agent API](/reference/agent-api.md) and [The agent boundary](/explanation/the-agent-boundary.md). [Configuration](/reference/configuration.md#kasten_weather_places) and [Editor keys](/reference/editor-keys/finding.md#the-weather-card) say so.
* **Update**: a `[[wikilink]]` can name a page of HTML by its whole file name, `[[2026-10-07.html]]` or `[[news/2026-10-07.html]]`, and `gf`, Enter or Ctrl+click opens it in the focused pane. Completion offers the pages with their `.html` on. A link to a page nobody made stays dead rather than making a note. A folder move rewrites a link that spelled a moved page's path, and the graph draws no node for a page. [Editor keys](/reference/editor-keys/links.md#wikilinks), [HTTP API](/reference/http-api.md) and [Graph query](/reference/graph-query.md) say so, and the startup note `reading-this-vault.md` gained the `.html` case in step 1.
