# 2026-09-21

* **Update**: an agent with no MCP client reaches the vault through a Claude Code plugin that ships in this repository. The repository root is now a plugin marketplace, `.claude-plugin/marketplace.json`, listing one plugin, `plugins/kasten`, whose one skill, `vault`, drives the five `/agent/` routes with curl and a token held in `KASTEN_TOKEN` beside the base URL in `KASTEN_AGENT`. It exists for a machine whose Claude Code runs with MCP servers turned off by policy, where the token and the routes were already enough and only the knowledge of how to use them was missing. The skill carries the rules the MCP server's instructions carry, spelled in routes rather than tool names, and a docstring in `agent_mcp.py` says both copies change together, nothing reading one off the other. It leans on curl 8.3's `--variable` and its `:url` and `:json` functions rather than on `jq` or Python, which a locked-down machine is the likeliest to lack: a path holding spaces, umlauts, `#` and `?` is encoded by curl, `/` included, which uvicorn decodes before routing and which Cloudflare and Caddy pass through untouched, and a note's body is read from a file and escaped by curl, so no JSON is ever quoted by hand. The plugin carries no version, so Claude Code takes the commit as its version and a release of kasten owes the plugin no bump. [Connect an agent](/how-to/connect-an-agent.md) gained the install and the two variables.
