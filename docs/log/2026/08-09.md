# 2026-08-09

* **Creation**: Added [Cut a release](/how-to/cut-a-release.md). Production deploys on a published GitHub release and nothing had written down what to do before publishing one, so the version in `backend/pyproject.toml` sat at `0.1.0` through two releases and the backend reported a version behind the code serving it. The page reads the next version off the commit subjects, which are Conventional Commits and already say whether a range is a patch, a minor or a major, then bumps, tags, and checks what production actually reports. It also carries the rollback command and what to do when the tag and the version disagree.
* **Update**: [HTTP API](/reference/http-api.md) says `POST /api/files/{path}` takes an optional body carrying the note's text, in the shape `PUT` takes. The section no longer says there is no body. It says sent text goes under the frontmatter block and is stamped the way a save's text is, that a create without a body is still the block and nothing else, and why the body exists: the five periodic keys already know the text, and saving it straight over the note they had just made put a second event on `/api/events` a moment after the note opened, which a reader typing by then saw as another writer.
