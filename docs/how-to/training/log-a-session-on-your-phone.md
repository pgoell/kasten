# Log a session on your phone

Every set lands in today's daily note under `## Training` as you tap, so you
can put the phone away at any point. What each part does is in
[Training session](/reference/training/session-screen.md).

You need the exercise notes in the vault: see
[Import the exercise library](/how-to/training/import-the-exercise-library.md).

## 1. Start

Open today's note (`Today` on the start screen, or the daily note key) and
tap `Start session` on the training card. Allow the screen to stay on if the
phone asks.

## 2. Pick an exercise

Tap one under `Today` or `Recent`, or type part of its name, German or
English, in the search field.

## 3. Log each set

Set the weight with `−` and `+`, then the reps, and tap how hard it was,
7 to 10. Both start at what you did last time. Tap `Set done, rest 2:00`.
The set shows in the list and the rest timer starts at the bottom; tap
`+30 s` for more or `Go` when you are ready. The phone buzzes when the rest
is over.

## 4. Move on

Tap `Next exercise` when you are done with it, or `Skip exercise` to leave one
out without writing anything, and pick the next.

## 5. Add cardio typed by hand

On the list, tap `Walk`, `Run` or `Ride`, set the minutes and the distance,
and tap `Save`.

## 6. Fix a mistake

Close the screen with `Done` and edit the line in the note, or press `u` in the
editor right away to take back the last set. The line is plain text, so
any edit counts.
