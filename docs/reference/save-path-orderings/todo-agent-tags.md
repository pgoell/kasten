# Save path orderings: agent tags and the editor's todo shortcut

Part of [save path orderings](/reference/save-path-orderings.md). The columns are explained in [How to read the table](/reference/save-path-orderings.md#how-to-read-the-table). Rows keep their numbers on every page, so "As 82" points to the same row wherever it sits.

## Orderings

| # | Ordering | Must hold | Loses typed text if wrong | Test |
|---|---|---|---|---|
| 130 | The todo pane's `@`, or the phone strip's `agent`, on a row whose note no pane is typing into. | One write, in the note's write queue, through `updateNote`: it reads the note, finds the row's todo, writes ` #agent` before the fields or takes it off an open todo, and names the text it read as its base, retrying on `Changed on disk`. Only the tag changes; the vault's answer goes in the cache. | no | home-route-agent-tag: `#523 A1 the pane's @ adds #agent before the fields`, `#523 A2 the pane's @ on an open todo carrying #agent takes it off`, `#523 A7 the pane's @ changes the tag and not one other byte of the note`, `#523 A9 the phone strip's agent adds #agent` (#523) |
| 131 | `@` while the note holds text a failed save left, while it is open to type in, or while a write of it is in the air; or the vault refuses the write. | Nothing is written; the notice says `Nothing moved:` and why. The guards of 120 are asked before the write and again inside it. | yes | home-route-agent-tag: `#523 A8 I3 the pane's @ writes nothing while the note holds text not yet saved`, `#523 A8 I3 the pane's @ that the vault refuses says Nothing moved and why` (#523) |
| 132 | `@` on a row whose line a write since has shifted, turned into another todo, or whose twins changed. | The write finds its todo as 124 to 126 do, by its exact words; short of that it writes nothing and the notice says `Nothing moved: that line has changed since it was listed`. A line deleted above the row, so the line at the row's number is another todo with the same words and `#agent` added, is refused the same way: only the row's exact words count, not the words with the tag put on or taken off. | no | home-route-agent-tag: `#523 I2 the pane's @ tags its todo after a line was written above it`, `#523 I2 the pane's @ on a twin tags that twin after a shift`, `#523 I2 the pane's @ on a line gone since the listing writes nothing and says so`, `#523 B1 the pane's @ on a row whose line was deleted leaves the tag on the todo below` (red before this fix) (#523) |
| 133 | Two `@` on one row before the list redraws, or quick presses on two rows with the same words. | Each `@` that lands remembers the line it wrote, under the row it was pressed on (path, line, listed words) and the time the pane's todo listing arrived. The next press on that row from the same listing, queued behind it, goes by the remembered line in place of the row's words, as 132 finds a line, so it takes the tag off again. It goes by it only where the note holds exactly one line with those words; with none or several it writes nothing and says `Nothing moved: that line has changed since it was listed`. A press that lands replaces the remembered line and drops those from an older listing; a press that writes nothing leaves it for the next. | no | home-route-agent-tag: `#523 I5 two @ before the list redraws add the tag and take it off again`, `#523 B1 three quick @ on two rows of the same words each press their own todo` (red before this fix), `#523 B2 a second @ whose line now has a twin below a deleted line writes nothing and says so` (red before this fix) (#523) |
| 134 | `<leader>@` in the editor, or the palette's entry. | An edit of the buffer, one transaction, which autosave writes like any typing: no write of its own, and `u` takes it back. | no | keybindings: `#523 I1 one u takes back the whole of <leader>@ on a plain line`, `#523 A4 A7 <leader>@ with vim on adds #agent at the end of the words, before the fields`; palette: `#523 A9 sends a todo to the agent from a tapped row, no vim in the editor` (#523) |
