# Tutorials

Lessons for someone who has not run kasten before. Follow them in order and
they work; they are not the shortest path, they are the one that teaches.

* [Self-host on a server](self-host-on-a-server.md): run kasten for real, from an empty Linux server to a notebook at your own address behind a password, with a first note and Claude Code connected
* [Getting started](getting-started.md): run kasten for development, from a fresh clone to a local notebook with notes of your own in it
